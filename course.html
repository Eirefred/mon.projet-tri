MON PROJET RUN

Qu'est-ce que Mon Projet Run ?

Mon Projet Run est une extension de Mon Projet Tri. Nous avons créé ce volet spécifique pour accompagner exclusivement ceux qui ont la course à pied comme projet principal. Tout comme notre volet triathlon, nous offrons un mentorat connecté accessible partout au Québec pour vous aider à franchir vos lignes d'arrivée.
